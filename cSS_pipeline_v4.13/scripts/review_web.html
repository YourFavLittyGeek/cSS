How to use the reviewer

The reading. Each candidate is a dark structure the detector found near the cortex. It is outlined in red on the whole slice and an arrow shows where it is (nothing is zoomed in for you: zoom and pan as you like). Compare with the other planes and sequences, then give one decision. The decision is saved at once; the next unread candidate opens (Auto-next, G). When all are read, press Q for the summary and the 0–4 score. Everything is also in the menu bar and in the right-click menu on the image.

The AI meter

The needle shows a number from 0 to 1: red below 0.33 (the detector suspects a vessel, artifact or normal cortex), yellow 0.33–0.66 (uncertain), green 0.66 and above (suspects cSS). The line under it says what it suspects and why.
It is not a probability and has not been validated. It is the detector's rule-based evidence (shape, position on the cortex, both banks, vessel continuation), lowered when its vessel / artifact rules fire. Use it as a second opinion only: the decision is yours. Seeing it before you decide can bias you — hide it with K for any reading that is used to test the detector. The Calls summary tab (F3) lists the meter next to your calls: "agree" = you called cSS and it is green, or you called something else and it is red; yellow counts as neither.

The right panel

Drag the thin handle on its left edge to resize it (the width is remembered). Hide, Space or a click on the active tab hides it; vertical buttons then appear at the right edge and a click on one opens the panel on that tab. Tick Auto-hide panel (also in the right-click and Settings menus) and the panel appears only while the pointer is over those buttons or the panel; the pin symbol on the buttons pins it again. The tab you used last is reopened next time.

Snapshots

Take snapshot (Ctrl+S) saves the image you are looking at, with the overlays you chose, as a PNG or JPEG named with the study code, candidate number, the x y z voxel position of the lesion and the plane, for example M04_cand12_x082_y162_z099_axial.png. If a default folder is set it saves there at once; if not, the Save-as window opens. Save snapshot as… always asks. Settings → Snapshot settings… holds the folder, overlays, format, resolution and file name parts. The window itself (menus and panel) is not part of a snapshot. Names contain the study code only, never a patient name.

The final score

Q scores your calls. Each hemisphere gets 0 (no cSS), 1 (one sulcus or up to 3 immediately adjacent sulci) or 2 (two or more non-adjacent sulci, or more than 3 adjacent sulci); the total is 0–4. Category: focal = 1–3 sulci, disseminated (diffuse) = more than 3 sulci. Several pieces of one continuous lining count as one line and never raise the score. Before the final save a window compares your calls and score with the AI's; from there you can re-review any disagreement, then Save final. The window can be switched off there or in the Settings menu. The final scores go to review/css_report.xlsx. The AI score is the same scoring applied to the candidates in the meter's green band; it is not validated.

Marking a cSS the detector missed

Press X (or right-click → Mark a missed cSS here). A small bar appears: draw a rectangle around the lesion (default) or trace it with the pen (W switches; several pen strokes are allowed, Backspace removes the last one). Type a note if you wish, then Save (Enter); Esc cancels. Mark the one slice where the lesion is clearest. Saved marks are listed in the Candidates tab with what the detector did at that place (shown, excluded by a rule, below a size gate, or not generated). They are reported next to the score but are not counted in the 0–4 score.

Other tools

Darkness probe: mean signal of the 3 × 3 voxels under the click, as a percentage of the normal cortex and in standard deviations below it (candidates start at about −2.5 SD). Ruler: drag a line, length in mm. Magnifier: a lens follows the mouse. Sequences that are not listed were not imported for this patient.

Everything is stored on this computer in the project's review folder, with the reviewer name and time. Close with Esc.

Before saving: AI vs reviewer

The AI calls and the AI score come from the detector's rule-based evidence. They are not validated: a difference shows where you and the rules disagree, not who is right. Calls you change after seeing this window are recorded as re-votes.

Import earlier calls

A new reviewer name starts empty. Copy calls from another file onto your list. Imported calls are dashed until you press the same key again; then they count as yours.
