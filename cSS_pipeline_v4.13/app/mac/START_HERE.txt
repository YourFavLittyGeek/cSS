cSS Pipeline app - first start (no Terminal)
1. Drag "cSS Pipeline.app" into Applications.
2. The first time only: right-click it -> Open -> Open (macOS asks because the app is not from the App Store).
3. Home screen: Setup check. If FreeSurfer shows ✗, go to Settings -> FreeSurfer folder -> Choose... (/Applications/freesurfer/8.2.0).
4. Home -> "Install / update from zip..." -> choose cSS_pipeline_v5.11.0-phase1_app1.zip (installs the matching pipeline; a backup is kept).
5. Add patients -> Choose folder... -> check the table -> Review summary -> Start processing.
Needs: Miniforge with the "css" environment and FreeSurfer 8 (both already on this Mac).
