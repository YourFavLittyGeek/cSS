  Non-measured inputs: `cmb_like` (rule flag) and `is_ball` / `is_tube` / `is_ribbon` (indicators of the rule-derived `struct_cls`).
  Missing values: training median (no missingness indicator) - a structurally unmeasurable `struct_*` or `tram_frac` is treated as an average object.
- **v5.2 ranker** (`train_ranker.FEATURES`, 52 inputs incl. 11 pial-surface `surf_*` from a separate file and 4 missing-input
  indicators): includes `mimic_score`, a RULE-DERIVED score (`mimic_rules.py`), as a feature - flagged. Never trained (no `labels/consensus.csv`).
- **unified score** (`uscore.common.PREDICTORS`): x1_vessel_continuity_mm, x2_core_contrast_nu, x3_pial_distance_mm, x4_sulcal_alignment, x5_extracranial_mm - computed from the images by `uscore/features.py`, not from the
  detector table; unreliable values contribute 0 (training-mean imputation after standardisation). Predeclared fallback drops x4 then x5.

## Excluded from every model, with reasons

- identifiers, the reader decision, provenance text and versions: carry no lesion property; ids are rank / position artefacts;
- MATH outputs (`score*`, `css_evidence`, `vein_evidence`) and rule flags: they are the MATH component; as predictors they would count MATH twice;
- `confidence_pct` / `confidence_why` / `conf_guard` and any `score_model`: outputs of learned models fitted on the same reads - circular;
- deprecated `vein_tree_mm`, `mirror_dark_frac`, `branch_per10mm`: saturate or carry no information (CLAUDE.md v4.x findings);
- quality columns enter the fusion QUALITY channel (gating), never the evidence.
